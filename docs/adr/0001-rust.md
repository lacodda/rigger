# ADR 0001: Rust as the implementation language

- Status: accepted
- Date: 2026-09-04

## Context

rigger is a daily-driver CLI and, later, an MCP server and a desktop window. It must install as a single binary on Windows, macOS and Linux, start instantly, open a local SQLite file and read git repositories in-process. On a corporate Windows machine it must work where scripts are forbidden by policy, which rules out anything that needs an interpreter or a `.ps1` shim. The author's line of tools is Rust-based, and the desktop shell it will later reuse (Tauri) is Rust too.

## Decision

Implement rigger in Rust. Core crates: clap (CLI), rusqlite with the bundled SQLite (storage), directories (data paths), gix (reading git without spawning `git`), serde/serde_json (packets and the MCP protocol).

## Consequences

- One static binary, no runtime for users and no script that a policy can block.
- Cross-platform CI on all three OSes - paths and the data directory are platform-specific.
- Slower iteration than a scripting language; acceptable for a long-lived tool whose surface grows one release at a time.
